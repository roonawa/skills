# WordPress QA local UI

目的: 既存ハーネスの状態をブラウザーで確認・実行できるローカルアプリにする。既存CLIとresults.jsonを唯一の検査結果とする。

採用: Node標準HTTPサーバー＋HTML/CSS/JavaScript。追加ランタイム依存なし。127.0.0.1に限定し、起動時に指定したサイト設定のみ実行可能。未指定時は隔離した同梱デモを起動する。外部ホスティングは行わない。

画面: サイト選択、実行履歴、suite選択と実行、進捗、状態別フィルタ、項目詳細、画像/ログ/HTMLレポート、基準画像の明示承認。状態は既存6種類と実行中を区別。公開可否を独自に再計算しない。

- [x] APIの設定登録・履歴・実行・証拠アクセス・Origin/CSRF制御をテストして実装
- [x] reporterの進捗保存とCLIの開始通知を追加し既存動作を維持
- [x] UIと詳細表示を実装。初回・空・実行中・失敗・通信失敗の状態を表示
- [x] ローカルデモでブラウザー操作テスト、画像確認、既存回帰検証
- [x] 利用手順とSkillのUI導線を更新、起動して利用者に渡す

境界: 設定JSON編集・モジュールのアップロード・任意コマンド実行・公開操作・マルチユーザー機能は追加しない。登録済み設定から既存CLIだけを引数配列で起動する。状態変更は同一Originと起動ごとのトークンを要求。証拠ファイルは台帳内の明示ファイルに限定。
