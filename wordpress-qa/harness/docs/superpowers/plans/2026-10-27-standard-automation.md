# 共通登録の自動検査拡張

目的: 新規登録全サイトで、判定可能な公開画面検査を生成・実行し、既存検査と重複した確認待ちを除く。観測値を正解として自動承認しない。

1. `lib/checks/standard.mjs`: SEO構造、フォーム制約、内部ナビゲーション、キーボード到達、計測タグ構造、多言語リンク、性能参考測定を実装。代表ページ最大5件。GET以外の外部送信を拒否。証拠に件数・検査範囲・未検証事項を保存。
2. `ui/public/case-generator.js`: 共有・ローカルの新規登録で自動ケースを生成。元の包括観点のうち、業務期待値・人間判断・外部連携を必要とする範囲は別途明示。
3. `ui/registration.mjs`: 登録済みadmin/journeyと重複する観点を整理。未設定を一律human-reviewへ変換する処理を廃止。設定不足と本当の手動評価を区別。
4. 自動生成の再実行は冪等とし、明示設定を上書きしない。既存プロジェクトの追加はバックアップ付きで行い、過去結果は保存する。
5. 単体・模擬サイトのブラウザー検査で正常/異常、送信禁止、同一オリジン制約、生成冪等性を検証する。対象サイトでも追加した読み取り検査を実行し、結果をUIに保存する。

残る範囲: デザイン/文章/初回画像承認、読み上げの利用感、通知の実配送、独自決済/会員/別ロール、更新と隔離復元、計測イベント仕様。設定不足を合格にしない。
