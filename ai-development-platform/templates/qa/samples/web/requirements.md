# 備品貸出アプリ 要件定義書（見本・架空）

社内の備品（ノート PC、プロジェクターなど）の貸出を記録する Web アプリです。旧版（http://localhost:4101）から新版（http://localhost:4102）へ改修します。

## 1. ロール

1.1 staff は一般職員です。自分が登録した貸出だけを見られ、貸出を登録できます。
1.2 admin は管理者です。全員の貸出を見られ、CSV 出力ができます。staff は CSV 出力できません。

## 2. ログイン

2.1 ユーザー名とパスワードのフォームでログインする。
2.2 認証に失敗したときは、ユーザー名とパスワードのどちらが誤りかを示さず、ログイン画面にエラーを表示する。
2.3 ログインしていない状態で一覧、詳細、登録、CSV の URL を開いたときは、ログイン画面へ移す。

## 3. 一覧

3.1 staff には自分の貸出、admin には全員の貸出を表示する。
3.2 貸出が 0 件のときは、表の代わりに「貸出はありません」と表示する。
3.3 1 ページに 50 件を表示し、51 件以上あるときは前へ・次へで移る。最終ページでは次へを使えない。
3.4 並び順は貸出日の新しい順とする。同じ貸出日の行は貸出 ID の大きい順とする。旧版は貸出日の古い順だった。これは今回の仕様変更である。

## 4. 詳細

4.1 一覧の行を選ぶと、貸出の詳細（備品名、借りた人、貸出日、返却予定日、備考）を表示する。
4.2 staff は他の人の貸出の詳細を開けない。URL に他人の貸出 ID を直接入れた場合も、一覧に出ていないかどうかにかかわらず 403 を返し、内容を表示しない。admin は全件を開ける。
4.3 存在しない貸出 ID のときは 404 を返す。

## 5. 登録

5.1 入力項目は、備品名（必須、50 文字以内）、貸出日（必須）、返却予定日（必須）、備考（任意、200 文字以内）とする。
5.2 返却予定日は貸出日以後で、貸出日から 30 日以内でなければならない。範囲外のときはエラーを表示し、登録しない。
5.3 登録に成功したら、借りた人としてログイン中のユーザーを記録し、一覧へ戻る。

## 6. CSV 出力

6.1 admin は一覧画面の「CSV 出力」で、全員の貸出を CSV でダウンロードできる。
6.2 1 行目は見出し行で、「貸出ID,備品名,借りた人,貸出日,返却予定日」とする。2 行目以降は同じ列順で貸出を 1 行ずつ出力し、日付は yyyy-MM-dd とする。文字コードは UTF-8 とする。
6.3 staff が CSV の URL を直接開いたときは 403 を返す。
