# 受け入れ条件

- AC-001: 正しい資格情報でログインでき、誤った資格情報ではログイン画面にエラーが出る（出どころ: requirements.md 2.1）
- AC-002: 未ログインで一覧、詳細、登録、CSV の URL を開くとログイン画面へ移る（出どころ: requirements.md 2.3）
- AC-003: staff の一覧には自分の貸出だけが出て、admin の一覧には全員の貸出が出る（出どころ: requirements.md 3.1）
- AC-004: 貸出が 0 件のとき一覧に「貸出はありません」が出る（出どころ: requirements.md 3.2）
- AC-005: 51 件以上あるとき 1 ページに 50 件出て、前へ・次へで移れ、最終ページでは次へを使えない（出どころ: requirements.md 3.3）
- AC-006: 一覧が貸出日の新しい順に並び、同じ貸出日では貸出 ID の大きい順になる（出どころ: requirements.md 3.4）
- AC-007: 詳細画面に備品名、借りた人、貸出日、返却予定日、備考が出る（出どころ: requirements.md 4.1）
- AC-008: staff が他人の貸出の詳細 URL を直接開くと 403 になり、内容が表示されない（出どころ: requirements.md 4.2）
- AC-009: admin は他人の貸出の詳細を開ける（出どころ: requirements.md 4.2）
- AC-010: 存在しない貸出 ID の詳細は 404 になる（出どころ: requirements.md 4.3）
- AC-011: 必須項目が空、または文字数の上限を超えると、登録されずエラーが出る（出どころ: requirements.md 5.1）
- AC-012: 返却予定日が貸出日より前、または貸出日から 31 日以上後だと登録されない。当日と 30 日後は登録できる（出どころ: requirements.md 5.2）
- AC-013: 登録した貸出に、ログイン中のユーザーが借りた人として記録される（出どころ: requirements.md 5.3）
- AC-014: admin の CSV の 1 行目が「貸出ID,備品名,借りた人,貸出日,返却予定日」で、2 行目以降に全員の貸出が同じ列順で出て、日付は yyyy-MM-dd になる（出どころ: requirements.md 6.2）
- AC-015: staff が CSV の URL を直接開くと 403 になる（出どころ: requirements.md 6.3）
