# 在庫一覧アプリ 要件定義書（見本・架空）

倉庫の在庫を一覧で確認し、保存や削除ができる Windows 用の WPF アプリです。

## 1. 一覧

1.1 起動すると、品名、数量、置き場所の列を持つ在庫の表を表示する。
1.2 行をクリックすると、その行が選択され、ステータスバーに「選択中: 品名」と表示される。
1.3 行の選択は 1 行だけとし、別の行を選ぶと前の選択は外れる。

## 2. 保存

2.1 「保存」ボタンを押すと、ファイル保存ダイアログを開く。既定のファイル名は stock.csv とする。
2.2 保存ダイアログで保存先を決めると、表の内容を CSV で保存し、ステータスバーに「保存しました」と表示する。
2.3 保存ダイアログでキャンセルしたときは、何も保存せず、メッセージも出さない。

## 3. 削除

3.1 行を選択して「削除」ボタンを押すと、「この在庫を削除しますか」の確認メッセージボックスを表示する。
3.2 確認で「はい」を選ぶと、選択した行を表から消す。「いいえ」を選ぶと、何も変えない。
3.3 行を選択していない状態で「削除」ボタンを押したときは、確認を出さず、「削除する行を選んでください」の警告メッセージボックスを表示する。表は変えない。
