# Retro Web Styling

## Overview
既存のHTMLを、2000年代前半の日本の個人ホームページ・ブログに特有の「痛い」デザイン(過剰な装飾、テーブルレイアウト、非推奨タグ)へと意図的に作り替える。洗練されたAI生成HTMLがもたらす「無難さ」を壊し、読み手に強い懐かしさとインパクトを与えることが目的。
生成時には、ファイルを上書きせず、元のHTMLを保持したまま、末尾に'-retro'を付加した別ファイルとして出力する。

## When to Use
- 利用者が「懐かしいデザインにして」「レトロなHTMLにして」のように、明示的に懐かしい/レトロなデザインへの変換を依頼したとき
- 使わない: 「モダンに」「シンプルに」「洗練させて」など、それ以外のデザイン変更依頼

## Core Pattern
モダンなHTML/CSSの「正解」とされる作法を意図的に反転させる:

| モダンな作法 | このスキルでの反転 |
|---|---|
| `<div>`+CSSでのレイアウト | `<table>`の多重入れ子でページ全体を構築(`div`は使わない) |
| 控えめな配色・余白 | 原色・グラデーション or タイル画像(`bg_pattern.gif`)の敷き詰め背景 |
| アクセシブルな静的テキスト | `<marquee>`での点滅+横スクロールテキスト(例:「いらっしゃいませ！！！」) |
| シンプルなナビゲーション | フレーム分割・BBS風・リンク集/相互リンクのダミー要素 |
| 訪問数を表示しない | アクセスカウンター・キリ番文化(「あなたは●番目のお客様です」) |
| モダンなローディング表現 | 「工事中」「NEW‼️」の2コマピコピコGIFループ(`under_construction.gif`, `new.gif`) |

参考実例: https://hogehoge.co.jp/ (工事中GIF・ボタンナビ・アクセスカウンター・キリ番掲示板を備えた実例)

## Quick Reference

盛り込む要素(該当するものを組み合わせる):
- アクセスカウンター・来訪者カウンター・キリ番文化
- テーブルレイアウト(`<table>`多重入れ子、`div`不使用)
- `<marquee>`による点滅+横スクロールテキスト
- 派手なグラデーション背景 or タイル画像背景
- 「工事中」「NEW‼️」2コマGIFアニメのループ
- フレーム分割レイアウト風の演出
- BBS(電子掲示板)文化風のダミー要素
- リンク集・相互リンク風ダミー、ネットマナーページへのパロディリンク
- 右クリック禁止ポップアップ
- 虹色罫線(`<hr size color noshade>`風)のセル・境界装飾
- マウスカーソル追従のキラキラエフェクト(`mousemove`でstar要素を生成しfadeさせる)
- 「いらっしゃいませ」→「ようこそ我が聖域へ」的な表現に変更
- 「上長」→「主（ぬし）」「騎士」等の表現を検討
- †や★などの装飾記号を増やす
- 「〜だったりします」「〜なのです」等の当時の語尾を追加
- 「闇」「光」「魂」等の厨二ワードを適所に配置
- HTMLコメントにも当時感のあるメッセージを追加

対象外:
- 実際の1990年代ブラウザ互換性の再現(Netscape 4対応など)は行わない
- 文章内容は変更してよいが、意味・情報は保持する(情報構造そのものを壊さない)

## Implementation

1. 元のHTMLの情報構造(見出し階層、ナビゲーション、本文の意味)を確認し、保持すべき情報を洗い出す。
2. ページ全体のレイアウトを`<table>`の多重入れ子に置き換える(`div`は使用しない)。
3. Quick Referenceの要素から、ページの分量・内容に合うものを組み合わせて追加する。すべてを詰め込む必要はないが、最低でもアクセスカウンター・`<marquee>`テキスト・工事中/NEW GIF・虹色罫線は含めることを基本とする。
4. `<marquee>`タグを実際に使用しつつ、動作しないブラウザ向けにCSSアニメーション(`@keyframes`)でのフォールバックも用意する(Common Mistakes参照)。
5. マウスカーソル追従のキラキラエフェクトは、`mousemove`イベントで星型のdiv要素を生成しCSSアニメーションでfadeさせるJSで実装する。
6. 元の文章は意味が通じる範囲で書き換えてよいが、情報自体は削らない。

### プレビュー時の確認チェックリスト
1. タイトルが原色・ポップな装飾で表示されている
2. アクセスカウンターの数字が表示され、キリ番の演出がある
3. マウスカーソル追従のキラキラエフェクトが動作する
4. `<marquee>`テキストが点滅しながら左右に流れる(フォールバックのCSSアニメーションも動作確認する)
5. 右クリックでポップアップ(アラート等)が出る

## Common Mistakes
- **`<marquee>`をフォールバックなしで使う**: 一部のモダンブラウザでは`<marquee>`が正しく動作しない場合がある。CSSアニメーション(`@keyframes`)による代替表現を必ず併記し、どちらか一方でも懐かしい演出が伝わるようにする。
- **装飾過多で情報が読めなくなる**: 点滅・マーキー・原色背景を全要素に適用し、本来伝えるべき文章や重要なリンクまで埋もれさせない。
- **`div`を紛れ込ませる**: テーブルレイアウトを基本方針としているのに、一部だけ`div`でレイアウトしてしまうと世界観が崩れる。
